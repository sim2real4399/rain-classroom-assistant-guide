# 下载、安装与作业运行

适用：Windows 电脑上的 Chrome / Edge，雨课堂 ai-workspace/lms-graph 作业页。教程配图是示意图，实际按钮随版本变化。

## 1. 安装 Tampermonkey

从 [官网](https://www.tampermonkey.net/)进入自己浏览器的官方扩展商店安装。在工具栏扩展列表找到 Tampermonkey，可固定图标。油猴安装完后，还需导入本仓库的 .user.js。

## 2. 授予运行权限

打开 Edge 的 edge://extensions/ 或 Chrome 的 chrome://extensions/，进入油猴详情。按界面启用「允许用户脚本」；官方 Q209 说明 Chrome 138+ 提供此开关，部分环境需要开发者模式。见 [官方说明](https://www.tampermonkey.net/faq.php#Q209)，不要把不同浏览器截图当作完全相同的步骤。

## 3. 导入脚本

### Raw 安装

仓库点开 yuketang-ComplexAutomation.user.js，再点 Raw。油猴若打开安装页，点击安装 / 更新。

### 文件导入

1. 仓库首页 Code → Download ZIP。
2. 解压，找到 yuketang-ComplexAutomation.user.js。
3. 油猴管理面板 → 实用工具 → 从文件导入。
4. 选择 .user.js，确认安装，仅启用一份同名脚本。

导入的是脚本文件，不是 ZIP 或整个仓库文件夹。

## 4. 显示面板

回到 yuketang.cn 下、路径含 /ai-workspace/lms-graph/ 的作业页刷新。面板未出现时，油猴菜单点「显示/恢复雨课堂助手面板」。

该菜单也没有时，检查：网址匹配、脚本启用状态、用户脚本运行权限、依赖是否成功加载。已启用不等于已成功执行。若网页曾移除旧面板，恢复前会终止旧执行；按提示刷新再开始。

## 5. 设置与测试

按 [模型配置表](02-model-and-troubleshooting.md)保存参数，同时勾选：

- 自动作答作业与题目。
- 仅作答作业（跳过视频、音频、课件和讨论）。

在课程允许 AI 辅助的练习中先测试一道题，确认模型返回、选项状态与提交结果。再展开所需目录，从当前作业开始。

脚本会自动选择选项并可能提交题目，使用时检查页面和日志；模型回复不等于正确答案。

## 6. 停止与范围

立即停手应点「终止」。暂停只挂起部分流程，在途模型请求可能继续。

脚本尝试识别可见安全校验标题并硬停。请人工验证 → 刷新 → 重新开始；它不识别验证码轨迹，跨域或图片中的校验文字也可能漏检，必要时手动终止。

仅处理当前与后续已加载在左侧目录中的作业，不保证覆盖此前作业、未加载章节和平台尚未解锁内容。仅作业模式关闭后恢复上游顺序处理学习项的行为。
